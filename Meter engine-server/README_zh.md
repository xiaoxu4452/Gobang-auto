# 五子棋桌面助手（Gomoku Desktop Assistant）

屏幕识别版五子棋辅助面板。运行时自动抓取屏幕上的棋盘、调用本地引擎评估，并在桌面上叠加
**推荐落点蓝圈、四档热力图、对手预测环**等辅助信息。双击即可用，无需手动配置。

---

## 一、系统要求

- **操作系统**：Windows 10 / 11（64 位）。
- **WebView2 运行组件**：Windows 11 与多数 Windows 10 已随 Edge 自带；若缺失，请安装一次
  「Microsoft Edge WebView2 Runtime」（微软官网免费）。
- **引擎与识别**：无需单独安装。`Desktop GomokuOverlay.exe` 启动时会自动拉起共用的引擎
  （`Web GomokuEngine.exe`，监听 `:8964`）与屏幕识别服务（监听 `:8971`）。如果这两个端口已被占用，
  程序会直接**复用**已有的进程，不会重复启动。

## 二、目录结构

本文件夹 `Desktop version/` 发布内容如下：

```
Desktop version/
├── Desktop GomokuOverlay.exe      # 主程序
├── overlay/               # 面板 UI（HTML + CSS + JS），由 WebView2 渲染
│   ├── panel.html
│   ├── panel-ui.js
│   └── bridge.js
├── README_zh.md           # 本文件（中文说明）
├── README_en.md           # English guide
└── logs/                  # 运行日志（自动滚动，见第四节）
    ├── overlay-YYYYMMDD-HHMMSS.log
    └── crash.log
```

## 三、使用方法

1. **双击 `Desktop GomokuOverlay.exe`**。
2. 会同时出现两样东西：
   - 一个**黑色 CMD 窗口**，里面是英文运行日志（见下）；
   - 屏幕右下角一个**半透明悬浮控制面板**。
3. 把对弈平台（如智子五子棋）的棋盘放到屏幕上，程序会自动识别棋盘、画出四角标记与棋盘框，
   并在落子时给出推荐。

### 面板功能

| 元素 | 含义 |
| --- | --- |
| 四角 L 型框 + 棋盘蓝紫框 | 标记识别到的棋盘位置 |
| **蓝色圆** | 推荐落点（我方视角） |
| **热力图** | 四档排名染色：青 → 绿 → 粉 → 浅粉；格内标注评估数字（我方视角，正=我优）。可在面板里**关闭**，并调**透明度** |
| **对手预测环** | 预测对手下一步应手。若只想看自己的推荐，可在面板里关闭「对手评估」 |
| 玻璃质感 / 透明度 | 已取消模糊，改用纯透明度（像玻璃般通透，不借助模糊）；浅色模式下文字为纯黑 |

### 重要行为

- **评估一次即冻结**：盘面没有变化时不会反复重新计算，匹配真实思考时间。
- **空盘检测**：当一帧里检测不到任何棋子、且连续两帧都如此，视为「棋盘已清空」并自动开新一局；
  新局会**复用上一局的棋盘几何**，避免开局坐标抖动。
- **关闭即退出**：点面板右上角的 **×** 会退出整个程序（包括底层引擎与识别服务）。

## 四、运行日志

日志放在 `logs/` 文件夹：

- 每 **15 分钟**生成一个新文件，命名 `overlay-YYYYMMDD-HHMMSS.log`；
- 文件夹内最多保留 **500 个**日志，超出后自动删除最旧的一个；
- 崩溃信息单独写入 `logs/crash.log`；
- 想让所有输出集中到一个固定文件（例如自动化测试），可用环境变量：
  `set GB_LOG_FILE=绝对路径\single.log`（程序会优先使用该路径，跳过滚动）。

日志窗口标题为英文 `Gomoku Desktop Assistant - runtime log`，内部每行也都是英文，便于排查。

## 五、常见问题

- **面板一直黑屏 / 超时提示**：多半是 WebView2 运行组件缺失，或安全软件拦截了它的子进程。
  先确认已安装 WebView2 Runtime；仍不行就看 `logs/` 里最新的日志与 `crash.log`。
- **识别不到棋盘**：检查棋盘是否在屏幕内、没有被窗口遮挡；可重开程序重试。
- **想完全退出**：关闭那个黑色 CMD 窗口，或点面板 × 即可。
