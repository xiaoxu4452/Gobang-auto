This directory contains a NATIVE (MSVC x64) build of Rapfi, compiled from the
official source with USE_AVX512/USE_AVX2 + USE_BMI2 + USE_VNNI and MULTI_THREADING.
Two binaries are shipped and the host picks one at startup by CPUID:
  RapfiEngine-avx512.exe  requires AVX512F/DQ/BW/VL + AVX512_VNNI
  RapfiEngine-avx2.exe    requires AVX2 + FMA + BMI2 (safe on any modern x64)
Build script: tools/build-rapfi-native.sh
Weights extraction: tools/extract-rapfi-networks.js
