0快速开始

三步上手：选模式 → 摆好或开下 → 用 AI 辅助与复盘提升棋力。

1

选模式：右侧「对局设置」卡里选 对弈 / 摆盘 / 残局。对弈时再开 AI 执黑 / AI 执白 开关。

2

开下 / 摆盘：对弈模式点棋盘落子；摆盘模式自由放子；残局模式摆好局面后点 确定 锁定。

3

提升：点 分析计算 看落点评估，用「计算评估」卡的 计算 / 前瞻 / VCF / VCT 找最佳手，再用「复盘」背诵。

💡 所有卡片右上角有「固定 / ✕」和一条横杠：横杠点一下折叠卡片；按住标题栏可把卡片拖到左侧或右侧、或调整顺序。

2三种模式

在右侧「对局设置」卡的 模式 虚线框里切换。三种模式决定棋盘上能做什么。

🆚 对弈（pve）

你与 AI 对局。开 AI 执黑 或 AI 执白 决定谁先走；两开关都关 = 你一人下双方；两开关都开 = AI 自己打自己（你旁观）。

底栏正中 ❚❚ 键 = 「AI 辅助落一子 / 暂停 / 自打开关」，随状态在 ▶ 与 ❚❚ 间切换。

🧩 摆盘（place）

自由摆放黑白双方任意子。用来练定式、造局面、复现棋谱。底栏 ❚❚ 键在此模式禁用（摆盘不会自动落子）。

配合低栏的 ⇄ 翻转、↻ 旋转、✥ 平移变换布局。

♟ 残局（endgame）

专练残局：棋盘下方出现摆盘行 确定 · 顺序摆盘 · 任意摆盘。

  • 顺序摆盘：黑白轮流落子。
  • 任意摆盘：弹小框选「黑子/白子」，可连续摆该色（如 30 黑 + 10 白）。
  • 确定：把当前盘定为本残局；此后「重新开始」回到此局面，存进历史时它也是首帧。

🔁 切换副作用

切到「残局」会自动清掉基准盘并进入摆盘；VC 载入或 openRecord-vc 同样清基准。残局记录带绿色 Endgame 徽标。

「重新开始」= 整个局面消失（已自动存进历史），不再铺回基准；打开历史才重新展开该残局。

3对局设置卡

右侧停靠栏最上方卡片，控制一局的所有参数。各控件如下。

控件说明
模式对弈 / 摆盘 / 残局（见第 2 节）
AI 执子两个独立拨动开关：AI 执黑(开=浅紫)、AI 执白(开=浅蓝)。
  • 只开执黑 → 你执白（AI 先手）
  • 只开执白 → 你执黑（你先手）
  • 都开 → AI 自打
  • 都关 → 你下双方
思考时间填秒（0.2~300，可三位小数）。AI 每手算多久。底栏/弹窗内同一含义。
规则① 无禁手　② 无禁手·长连不赢　③ 连珠（有禁手）　④ 山口(Yamaguchi)　⑤ 塔拉山口(Taraguchi)　⑥ 一手交换
核心数 / 哈希表引擎线程数与哈希表大小；按机器配置选。
并行引擎1 单引擎 / 2 双引擎投票 / 3 三引擎投票。多引擎不同线程数互补，对同手加权投票选最优。
摆棋评分勾选后在空点标出每手评估分（默认开）。
后台预热对手思考时后台持续计算，落子更快更深（默认开）。
显示序号棋子上标第几手。
预览框鼠标悬停时的圆角方框（默认开）。
局面代码复制 总代码 / 粘贴 / 载入。格式 = 小写列字母+行号逐手拼，如 h8h9g7…（与 gomocalc.com 同格式）。
📌 交换类规则（一手交换 / 山口 / 塔拉山口）交换完成后，棋盘下方会弹小窗让你亲自选「先手·执黑」或「后手·执白」，选定后 AI 自动执另一色并立即计算。

4落子与对局操作

棋盘底栏中段的按键负责走子与局面变换。

图 2 · 底栏中段对局键
  • ‹ / ›：回退 / 前进一步（浏览历史手顺）。
  • 重新开始：整局清空（当前局面已自动存入历史）。
  • ❚❚：AI 辅助落一子 / 暂停 / 自打开关。自由摆盘与残局模式下禁用。
  • 保存局面：把当前盘存进历史。
  • ↻ 旋转：整体棋子顺时针转 90°（坐标轴不动）。
  • ⇄ 翻转：弹小窗选「左右 / 上下 / ╲对角 / ╱对角」翻转棋子布局。
  • ✥ 平移：弹小窗向 ← ↑ ↓ → 平移一格（有子会出盘则整体不动并提示）。
  • 十打：开局引导行里的键，叫出 10 个候选点（仅开局流程出现）。
⚡ 底栏左段的 分析计算：点击开启「持续落点评估」——最佳点青色胶囊+边框，其余点青→红四色渐变（越差越红、填充越浅）；再点变「停止分析」清除所有评估标记。

5计算评估卡

右侧中间卡片，所有分析、算杀与热力视图都在此触发，结果直接标在棋盘上。

A六个分析键

键作用
多点分析列出当前局面最佳若干个候选点（数量由「分析点数」决定，最多 8）。棋盘上标名次徽标+评估分。
扫描防守在周围 N×M 方块扫描对手成形状凶点，百分比铺盘 + A/B/C 徽标（越要防越高）。
平衡一 / 平衡二两套平衡策略的评估对比。
计算主分析键（accent 蓝）。算的时候变「停止计算」，算完自动变回「计算」。
清除标记清掉计算评估里所有棋盘标记（含计算/多点/平衡/扫描 + 前瞻/VCF/VCT 的虚线与序号）。

B前瞻 / 算杀（VCF · VCT）

图 3 · 前瞻框：逐手推演 + VCF/VCT 算杀
  • 前瞻：逐手推演未来走法，框内显示推演进度与着法代码链（白子浅蓝框、黑子紫框），悬浮预览、点击选中、点「确定」落盘。
  • VCF：只搜连续冲四的必胜路线。
  • VCT：搜冲四 + 活三的必胜路线。
  • 选中键变浅粉紫；有解走完整条链，无解弹窗明确提示（进攻方由系统判定，不可手动点）。

CAI视图 / 指导视图（热力）

  • AI视图：AI 思考时只标出它准备下的那一点，落子即消失。
  • 指导视图：方形四色热力——AI 帮你算最佳落点，落子即消失。 ■最佳 ■良好 ■一般 ■劣势（四色图例见卡内）。
🧠 并行引擎设为 3 时，三条独立车道（不同线程数）对同一手同时搜，结果加权投票，落子与标注取最优；设为 1 即纯单引擎（对照/降级）。

6引擎仪表盘卡

右侧底部卡片，实时显示引擎状态与评估曲线（默认显示）。

  • 状态胶囊：绿点=空闲；红点脉冲+「计算中·功能名」=正在算。
  • 六项指标：深度 / 速度 / 节点 / 用时 / 评估 / 最佳（最佳=AI 推荐的下一手坐标）。
  • 评估曲线：黑子(紫)与白子(蓝)的评估分随手数滚动；左轴为固定刻度，右侧为横向滚动绘图区。
⚙ 卡片标题栏「固定 / ✕」：未固定显示「固定」（点后开别的卡它不被收起）；固定后变「✕」（点即取消固定并关闭）。横杠 = 折叠/展开；按住标题栏拖动换栏或调序。

7复盘窗口

点顶栏 复盘 打开独立窗口（Gomoku Review）。纯空盘进入时只有常驻键；选历史后才出现背诵/回顾键。

图 4 · 复盘窗功能键（选中历史后）
  • 背诵复盘：凭记忆逐手落子（不显示序号，靠脑记），错了记「背错 N」。
  • 回顾复盘：自动/手动一手手走，点「播放」按间隔(0.5~5s)自动播放，方向键 ←/→ 逐子操控。
  • ◀ ▶ / 胶囊 n / m：在记谱里步进。
  • 序号：给每颗子标第几手（复盘窗专属；主窗「显示序号」在这里不生效，避免背诵时泄答案）。
  • 重来 / 保存局面 / 历史：回到开局第 0 手 / 存盘 / 取一局。
⌨ 复盘窗快捷键：Ctrl+Z 上一手 · Ctrl+R 重来（回到第 0 手）。残局/VC 标记会随记录投到复盘窗，首帧即整个残局，背诵从残局后第一手起。

8识图窗口

点顶栏 识图 打开独立窗口（Gomoku Vision）：把截图/图片里的棋盘识别成可下局面。

图 5 · 识图窗功能键
  • 上传图片 / 屏幕截图：选图或截屏；可一次多张（≤150）。
  • 裁剪：拖矩形框选保留区域，确定后就地裁掉。
  • 翻页 ‹ n/m ›：多张之间切换；点胶囊 n/m 弹出左侧图片抽屉（缩略图选/移除）。
  • 识别：把图片里的棋盘识别成局面（结果同步到「棋盘代码」框）。
  • 保存到历史 / 加载到练习：存进历史，或发回主窗接着下（残盘居中加载 + 提示）。
  • VC 模式：算杀题模式。放行黑白子数不统一盘面，加载到练习后自动 VCF/VCT 模拟推演。
  • 修改：识别不准时人工微调。修改模式功能行：交换黑白子 / 删除棋子 / 补充黑子 / 补充白子 / 添加黑白子(成对) / 撤销。
⚠ 识别依赖自包含视觉引擎（GomokuVision.exe）。截图会自动贴盘（外扩约棋盘 1/30 并钳回虚拟屏）。如识别偏差，先用「裁剪」框住棋盘再识别，或用「修改」人工校正。

9历史管理

点顶栏 历史（或复盘窗内「历史」）弹出抽屉，管理所有对局与保存的局面。

图 6 · 历史抽屉
  • 两个标签页：历史（对局记录） / 保存历史（你永久保存的局）。
  • 全部选中：一键勾选当前页全部；再点取消全选（对两页都生效）。
  • 打开：把勾选的局载入（复盘窗里则进复盘窗）。
  • 保存选中：把勾选的局永久存入「保存历史」。
  • 删除 / 导入 / 导出：删除勾选；从 .txt 导入局面代码；导出选中局为 .txt（代码格式与 gomocalc 兼容）。
  • 右键菜单：每条历史右键 → 打开复盘 / 重命名 / 导出这一局 / 存入保存历史 / 删除。
🗂 残局记录带绿色 Endgame 徽标；VC 载入的记录也带相应标记随复盘投送。

10外观与配色

点顶栏 颜色 打开仿 PS 调色窗，自定义深浅主题与棋盘/背景色，全部持久化。

  • 主题：浅色 / 深色 / 自定义（一旦改色自动切「自定义」）。
  • 调色对象：棋盘 / 背景 二选一（选背景时不显示预制色）。
  • 取色盘：上方「饱和度×明度」方块 + 下方色相条，鼠标拖动取色。
  • RGB：R/G/B 三个数字框；也可直接填 #rrggbb 或 rgb(r,g,b) 代码框。
  • 预制色：选「棋盘」时出现一排预设棋盘色块，一键选用。
  • 恢复默认：还原出厂配色（棋盘 #d9b878 + 象牙白背景）。
🎨 配色、主题、语言(EN 键)都会首帧即时生效并持久化——下次启动直接是对的样子，不会闪一下默认色。
