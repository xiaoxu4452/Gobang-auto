Meter Gomoku pairs a strong engine with full visibility into what that engine is doing. It is not only a place to play — it exposes the whole search: depth, nodes, nodes per second, elapsed time, score, win rate and ranked candidate points, live on the board and dashboard.

02下载与安装Download & Install

  1. 下载压缩包后解压到英文路径（例如 D:\MeterGomoku）。路径里有中文或空格时，个别系统的引擎子进程可能起不来。
  2. 双击 Desktop GomokuTrainer.exe。首次启动会解压 NNUE 权重并分配置换表，大约 1～3 秒，之后每次启动都在 1 秒内。
  3. 目录里必须有 rapfi-native 文件夹（引擎与权重）和 calc\ui.pak（界面）。不要只拷 exe。
  4. 如果杀毒软件拦截 RapfiEngine-*.exe，请放行一次；引擎是标准控制台程序，通过管道通信。
  1. Unzip into an ASCII path such as D:\MeterGomoku. Non-ASCII characters or spaces in the path can prevent the engine subprocess from starting on some systems.
  2. Run Desktop GomokuTrainer.exe. The first launch unpacks the NNUE weights and allocates the hash table (1–3 s); later launches are under a second.
  3. Keep the rapfi-native folder (engine + weights) and calc\ui.pak (UI) next to the exe. Do not copy the exe alone.
  4. If antivirus flags RapfiEngine-*.exe, allow it once — it is a plain console program talking over pipes.
绿色软件：没有安装程序、不写注册表。删掉文件夹就是卸载；配置存在程序目录内的浏览器配置里。

04对局与使用方法Play & how to use it

默认进入对弈模式（空盘）。点任意交叉点落子；AI 执黑或执白时会自动应手。下面从开始一局、逐项设置到暂停键，把对局流程说明清楚。

The app opens in Play mode on an empty board. Click any intersection to place a stone; the AI answers whenever it owns Black or White. The guide below covers starting a game, every setting and the pause key.

快速开始Quick start

  1. 在右侧对局设置卡选择模式：对弈 / 摆盘 / 残局。
  2. 按需要打开AI 执黑或AI 执白；两个都不开＝黑白双方都由你自己下，两个都开＝AI 与 AI 自打。
  3. 设定思考时间（0.2～300 秒），这是 AI 每手的思考预算；时间越长棋力越强，CPU 占用也越高。
  4. 在棋盘交叉点点下第一子开始行棋；棋盘下方的AI 执子可以随时改执子方并立即行棋。
  5. 要清盘就点重新开始（当前这局会先自动存进历史）；要保存当前盘面就点保存局面。
  1. Pick a mode in the match card on the right: Play / Compose / Endgame.
  2. Turn on AI plays Black and/or AI plays White. Both off = you play both sides; both on = AI versus AI.
  3. Set the think time (0.2–300 s): the budget for each AI move. Longer is stronger, at the cost of CPU load.
  4. Click an intersection to start. The AI side button under the board switches sides on the fly and moves at once.
  5. Use Reset to clear the board (the current game is saved to History first), or Save to store the position.

05计算与分析Analysis

「计算评估」卡片里是全部的分析工具。它们共用一台引擎、一个队列 —— 同一时刻只跑一个任务，落子优先于后台分析，所以你不会看到「算一半被切断」的假分数。

The analysis card holds every tool. They share one engine and one queue — only one job runs at a time, and a real move always pre-empts background analysis, so you never see scores from a half-finished search.

摆盘 / 残局模式Compose & endgame

摆盘模式自由摆子，AI 完全不参与。残局模式用于「自己摆一个局面来研究」，棋盘下方会出现「确定 / 顺序摆盘 / 任意摆盘」：顺序摆盘＝黑白轮流落子；任意摆盘＝先选「黑子」或「白子」，再连续摆这一色，数量与顺序都不限。摆好后点「确定」定盘，按键变绿并显示「已确定」；再点一次解除，可以重新摆。残局模式下 AI 全程不参与，交换手类规则自动变灰。

Compose mode is free placement with no AI at all. Endgame mode is for building a position to study: the board toolbar gains Confirm / Sequential / Free. Sequential alternates Black and White; Free lets you pick Black or White and place that colour any number of times in any order. Confirm locks the position (the key turns green and reads “Confirmed”); press it again to release and keep editing. The AI stays out of Endgame mode, and swap-related rules are greyed out.

07复盘Review

顶栏「复盘」打开独立的复盘窗口，专为「把一盘棋读透」设计：

The Review window from the top bar is built for reading a game closely:

  • 背诵复盘：隐藏后面的手，凭记忆一手一手摆出来。摆错会立刻标红并计数，可以随时「重来」。
  • 回顾复盘：以 1 秒/手自动播放，速度可调；可开「序号」看手数，也可以随时跳到任意一手。
  • 复盘窗与主窗互不干扰：复盘只读局面，不会改动你正在下的棋。
  • Recite: later moves are hidden and you replay the game from memory. A wrong stone is flagged and counted; restart any time.
  • Replay: auto-plays at one move per second (adjustable), with optional move numbers and jump-to-move.
  • The review window reads the position only — it never disturbs the game in the main window.

08识图Vision

顶栏「识图」把一张图片或一段屏幕画面变成可以继续下的局面。

Vision turns a picture — or a piece of your screen — into a position you can keep playing.

  1. 上传图片 / 屏幕截图，然后裁剪到只剩棋盘。裁得越紧，识别越稳。
  2. 点识别，等待结果。识别参数（5 个阈值）在面板里可调，拖动即时生效并自动保存。
  3. 核对棋盘上的棋子，确认后加载到练习：局面直接进入摆盘模式，可以继续分析或对弈。
  4. VC 模式允许黑白子数不统一（残局、摆拍题常见），加载后自动跑一次 VCF/VCT。
  1. Upload or capture, then crop to the board only. Tighter crops recognise more reliably.
  2. Press Recognise. The five thresholds in the panel are live and auto-saved.
  3. Check the stones, then load into practice — the position lands in Compose mode, ready to analyse or continue.
  4. VC mode accepts uneven stone counts (common in puzzles) and runs a VCF/VCT pass after loading.
识别不准怎么办：先裁剪、再调阈值；棋盘有透视变形时先把它转正；深色主题的棋盘建议把「棋子对比度」阈值调低一档。
If recognition is off: crop first, then tune thresholds; straighten a skewed board; for dark boards lower the stone-contrast threshold by one step.

09连线Link

连线是「替你在别的程序里下棋」的功能：它不接管对方的程序，而是盯着屏幕。

Link plays for you inside another program — not by hooking it, but by watching the screen.

  1. 顶栏「连线」打开连线窗，点框选棋盘，在屏幕上拖出目标棋盘的范围。
  2. 点识别。框从紫色变成蓝绿色、四角出现 L 形角框＝识别成功。
  3. 选AI 执黑或AI 执白（互斥），设好思考时间。这些设置会同步回主窗。
  4. 识别在后台静默进行：画面静止时几乎零开销，棋子一变才重新读盘，读到你的回合就自动落子。
  1. Open Link, press Select board, drag a rectangle over the target board.
  2. Press Recognise. The frame turns from purple to teal with L-shaped corners = locked on.
  3. Pick AI plays Black or AI plays White (mutually exclusive) and a think time; both sync back to the main window.
  4. Recognition runs silently: nothing when the image is static, a re-read only when a stone appears, and a move as soon as it is the AI's turn.
分工：连线窗负责识别与行棋，主窗大棋盘只同步显示局面，不参与评估、不落子 —— 两侧不会互相抢引擎。关掉连线窗，主窗自动恢复原来的模式与设置。
Division of labour: the Link window recognises and moves; the main board only mirrors the position and never evaluates or plays, so the two never fight over the engine. Closing Link restores your previous mode.

10引擎与硬件Engine & hardware

棋力全部来自 Rapfi。软件把「能调的」和「不该动的」分开了：线程数、哈希、变体、权重、选点范围可以调；搜索的核心参数一律采用官方配置。

All strength comes from Rapfi. The app separates what you may tune from what should be left alone: threads, hash, variant, weights and candidate range are yours; the core search parameters stay at the official values.

项Item说明Detail
线程数Threads 默认＝物理核数（本机 8 核 → 8 线程）。物理核跑满比超线程更稳，评测抖动更小。Defaults to the physical core count (8 on an 8-core machine). Filling physical cores is steadier than over-subscribing with SMT.
哈希表Hash 置换表大小，越大越省重复搜索。默认按内存自适应，32 GB 机器给 1～2 GB 都合理。Transposition table size; bigger avoids re-searching. It adapts to your RAM by default; 1–2 GB is reasonable on 32 GB.
变体Variant sse / avx2 / avx512 / avx512vnni / avxvnni 五个二进制，启动时按 CPU 指令集自动挑，启动日志里会写「本机实测最快」。Five binaries (sse / avx2 / avx512 / avx512vnni / avxvnni), picked at startup from your CPU features; the log states which one was chosen.
权重Weights NNUE（默认，判断力强）或传统估值（更省算力）。NNUE (default, strongest judgement) or the classical evaluator (cheaper).
选点范围Candidate range 0 最窄（5×5）～ 5 全盘。窄＝同时间算得更深；宽＝不容易漏点。默认 3（7×7+4 线）是官方推荐档。0 (5×5) … 5 (whole board). Narrower searches deeper in the same time; wider misses fewer points. Default 3 (7×7 + 4 lines) is the recommended step.
最大深度 / 节点Max depth / nodes 上限保护：最大深度 4～128，最大节点 0.1～4096 M。留空＝由思考时间决定。Safety caps: max depth 4–128, max nodes 0.1–4096 M. Leave them empty to let think time decide.
关于 CPU 占用：搜索期间吃满线程数是正常的 —— 深度就是这么换来的。想安静一点，先把线程数降到一半，或缩短思考时间，而不是把引擎参数改散。
About CPU load: saturating the threads during a search is normal — that is where depth comes from. To keep things quiet, halve the threads or shorten think time rather than scattering engine parameters.

12常见问题FAQ

分数为什么和别的软件不一样？Why does the score differ from another program?

评估分是「相对当前行棋方」的原始分，不同引擎、不同阈值、不同搜索深度都会不同。判断强弱看胜率和最佳点更可靠；分数每次刷新略有跳动也正常，那是搜索还没收敛。

The score is a raw value relative to the side to move, so different engines, thresholds and depths all differ. Win rate and the best point are more reliable; small jitter between refreshes is normal before the search converges.

引擎没反应 / 一直「引擎还没就绪」Engine unresponsive / "engine not ready"

确认 rapfi-native 与权重文件还在 exe 旁边；路径不要有中文；被杀毒拦过就先放行再重启；内存吃紧时把哈希调小一档。

Check that rapfi-native and the weights still sit next to the exe; avoid non-ASCII paths; whitelist it if antivirus interfered; drop the hash one step if RAM is tight.

风扇很响、CPU 一直 100%Loud fans, CPU pinned at 100%

只要还有搜索在跑，引擎就会占满线程。关掉「分析计算」就恢复空闲；对弈只在 AI 回合搜索。

As long as a search is running the engine fills its threads. Turn off Analyse and it idles; during a game it only searches on the AI's turn.

换规则 / 开新局后评分很怪Odd score after switching rules or starting over

换规则会自动清空置换表并重置引擎；如果仍有异常，点一次「重新开始」，让第一手在干净状态下重新算。

Switching rules clears the hash and resets the engine. If something still looks off, hit Reset so the first move is searched from a clean state.

为什么有的候选点胜率都是 100%？Why are some candidates all at 100%?

说明引擎已经确认了必胜或必败（评分显示 +M12 这种杀棋值）。这时排名意义不大，看杀棋手数就行。

The engine has proven a forced win or loss (the score shows a mate value such as +M12). Ranking matters less then — read the mate distance instead.
