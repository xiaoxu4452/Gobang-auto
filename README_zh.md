# Gobang-auto · 米特五子棋（Meter Gomoku）—— 五子棋 AI 训练器、助手与连线工具

**米特五子棋（Meter Gomoku）**是一套基于原生 **RapFi** 引擎的 Windows 桌面 **五子棋 AI（Gomoku AI）**套件。RapFi 是目前开源界棋力最强的**五子棋（Gomoku / 连珠 / 五子连珠）AI 引擎**之一。本套件把 **AI 训练器**（分析、评估、VCF / VCT 算杀、禁手判定）、**实战助手**（屏幕识别 + 自动落子，辅助你在其他对局软件中下棋）与 **棋盘识别连线工具**（Gomoku Vision 视觉识别 + 引擎分析，辅助在线五子棋平台）整合在一起，全部本机运行、零 HTTP。

> **可直接运行整合包** —— 下方带 `Meter` 前缀的目录均为**已编译好的成品发布包**（可执行文件 + 加密 UI 资源 + 原生 RapFi 引擎 + 视觉识别服务），解压即可直接运行，无需任何构建步骤；`desktop-*` / `bookmark-assistant` 目录为对应的源码工程。

| 目录 | 说明 |
| --- | --- |
| `Meter Gomoku` | **成品**连线版——桌面覆盖层，支持棋盘识别、RapFi 引擎分析、交换平衡点提示、可选自动落子与复盘面板 |
| `Meter GomokuTrainer` | **成品**单机五子棋 AI 训练器——分析、摆盘、评估（含 VCF / VCT 算杀、禁手判定）、复盘与练习 |
| `Meter GomokuAssistant` | **成品**桌面五子棋助手——实时抓屏识别、评估覆盖层、交换平衡点 / 交换评估、自动落子（对战在线棋盘） |
| `Meter engine-server` | **成品**共享引擎服务——原生 RapFi 引擎构建 + 扫描 / 视觉识别服务 |

## 特性亮点

- **原生 RapFi 引擎**：开源最强五子棋 / 连珠 AI 引擎进程内硬连接（纯 C++ 硬链接、零 HTTP 往返），延迟低、棋力高。
- **单 Rapfi 高效变体 + 多线程协同搜索**：同一引擎变体、满线程数协同搜索同一博弈树，共享一张大分区置换表；实际哈希容量 = 你所选档位 × 2（每核不低于 128 MB，总表 ≤ 内存 80%、6 GB 硬顶），线程数严格同步你的选择。
- **单发独占分析**：每次分析与自动落子均走单发通道（`Analyze` 独占语义），评估与落子互不排队，充分发挥引擎智力。
- **交换平衡点 / 交换评估**：空盘交换（两黑一白）与中局交换（一黑一白）依据 RapFi 官方开局库计算，双方几乎零优势，避免暴露有利点；有禁手（连珠）、无禁手、长连不赢各自使用专属定式与评估线路。
- **屏幕识图（Gomoku Vision）**：把任意五子棋对局截图变成可继续研究的局面，训练器与连线助手共用。
- **识别覆盖层**：四个紫色 L 型角框 + 天蓝色连线、五个十字定位点、对覆盖窗口自身免疫、低高清固定比例缩放。
- **棋盘识别算法（原生、零 HTTP）**：整条识别管线在 C++ 宿主与视觉服务内完成，不依赖网络：
  1. **抓取**——目标区域直接取原始位图（共享内存 / 命名管道，不落 PNG），做二值化与黑白颜色分割，分离棋子与棋盘边框。
  2. **棋盘定位**——先匹配四个 L 型角锚点，再结合边框与棋子布局共同确认棋盘矩形（棋子快下满时依然可稳定找到棋盘）；识别区域向外扩并锁定，登记五个十字定位点用于坐标网格。
  3. **防抖动稳定器**——锁定固定区域后识别器收敛，只有棋盘明显移动 / 缩放才重新搜索；抑制瞬时漂移，避免把角坐标、行列序号误识别成棋子。
  4. **棋子分类**——逐格黑白判定，并对坐标序号（行号列号、星位等）免疫；跨帧平滑去除闪烁。
  5. **对自身免疫**——识别过程绝不抓取本套件自己的窗口与中空框选窗口（框选窗为物理点击穿透），UI 自身不会产生垃圾棋子。
  6. **自动 / 手动模式**——自动模式全屏扫描并锁定棋盘；手动模式用户框选一次后，仅运行找子 / 评子（不再反复搜索），管线更快更稳。
- **连线自动落子**：三级点击管线（PostMessage → SendInput → 真实鼠标）逐帧校验 + 整轮重试；「真实点击」模式用于只认真实鼠标的程序（自绘 / 防外挂窗口）。
- **WebView2 界面**：深浅色主题、中英文切换、内置微浏览器（搜索 / 导航 / 下载走系统另存为对话框）。
- **强化打包**：Inno Setup 安装包，带 Defender 友好签名选项与变体核查，可安装在较老的 Windows 机器上。

- Windows 10 / 11（x64），兼容较老版本与低分辨率屏幕。
- [Microsoft Edge WebView2 运行时](https://developer.microsoft.com/microsoft-edge/webview2/)（常青版）。

## 从源码构建（概要）

（1）安装 Visual Studio（C++ 工具链）、Windows SDK 与 WebView2 SDK。
（2）取得原生 RapFi 构建（`rapfi-native`），并按运行时预期放入发布目录。
（3）用各自的构建脚本构建各桌面工程（宿主 + WebView2 界面），再生成发布包所需的 `.enc` UI 资源。
