Meter GomokuTrainer · 五子棋训练器 使用说明
========================================

【怎么用】
1. 双击运行  Desktop GomokuTrainer.exe  （若系统提示缺少 WebView2 运行时，
   按弹窗指引安装 Microsoft Edge WebView2 即可，Win10/11 通常已自带）。
2. 全部计算都在本机完成：页面内 AI（Rapfi 引擎 wasm 版）随包自带，
   不需要联网、不需要任何服务端；棋盘识别（GomokuVision.exe）也随包自带，
   纯 C++编译的exe 单文件，不依赖 Python。

【主窗口】
1. 模式（顶栏二选一）：
   人机对弈   → 你执黑/白与内置 AI 对下，AI 走 :8964 本地引擎（自动拉起）；
   自由摆盘   → 直接在棋盘上摆子，AI 完全不参与（不分析、不热力、不落子）。
2. 对局设置：思考时间按**秒**填（0.2 ~ 300 秒）；规则含无禁手 / 长连不赢 /
   连珠禁手 / 一手交换；「预览框」勾选 = 鼠标悬停棋盘时显示的浅灰蓝圆角方框。
3. 停靠面板：顶栏「卡片」键控制显隐；卡片可拖标题栏在左右栏之间搬运、
   点标题栏小横杠收成长条。「计算评估」卡 = 计算 / 多点分析 / 扫描防守 / 平衡一 / 平衡二 /
   前瞻，结果直接画在棋盘上（数字 / W-L / ≡ 徽标 + 评估分），详见下两节。
4. 颜色：顶栏「颜色」键开调色窗，棋盘 / 页面背景自定义色（护眼牛皮纸黄 + 象牙白子为默认）。

【计算评估（顶栏「卡片」里勾上「计算评估」）】
这一卡是「不落子、只看结论」的分析台。所有分析**恒按当前行棋方**算（轮到谁就替谁算），
不用手动切换先后手；复盘窗口里整卡不可用（复盘是纯棋盘，不连引擎）。
分析结果的读法：棋盘上的圆圈里，上面小字是**名次**、下面小字是**评估分**；
卡片下部的清单同时列出「名次 · 坐标 · 评估 · 最佳线(PV)」。

1. 计算 / 停止计算（**同一颗键**，文字随状态变）
   · 闲着时显示「计算」：点它 = 单路深算当前局面的**最佳一手**。这一档把时间预算放大到
     「思考时间 × 1.6」，线程全砸在一条主变例上，中残盘的杀棋与防守看得最深。
   · 算的过程中显示「停止计算」并点亮：点它 = 中断（引擎那一次搜索停不掉，
     但结果会被作废丢弃，不再画到盘上）。
   · 自然算完会自动变回「计算」，并顺带把右边的「引擎仪表盘」和「评估曲线」填上。
2. 多点分析
   一次问出**前 N 个**候选点（N = 卡里「分析点数」，可填 2~8，默认 4），
   棋盘按名次配色标出 1…N（1 红 → 2 橙 → 3 琥珀 → 4 青 …），一眼分得出先后。
   用途：不满足于「只有一个答案」时横向比较——比如看看第二、第三好点差多少分，
   或者判断某手是不是「唯一解」。
3. 扫描防守
   在**对手刚落那一手**周围 9×9 的范围里逐点打分，把百分比铺在棋盘上：
   % 越高 = 对手在这里能长出的形状越凶 = 越需要防。最要紧的点再叠 **W / L 徽标**：
   · Wn = 我若走这里，还有 n 步成五（W1 = 一手连五，W3 = 成活四，W5 = 四三，W7 = 双活三）；
   · Ln = 我若不挡，对手还有 n 步成五（L2 = 对手一手连五，L4 = 活四，L6 = 活三）。
   这一档是**页面内的形状启发式**，不走引擎，所以当场出结果；随后引擎精修会持续刷新
   到结论稳定（框里会提示「已稳定」）。用途：快速找「必须防的点」，尤其对手刚做完一个形。
4. 平衡一（一手平衡）
   先把前 N 个候选全算出来，再挑**评估绝对值最小**（|评估| 最接近 0）的那一手，
   棋盘上用绿色 ≡ 徽标标出，其余候选照常按名次列出。
   用途：局面已经占优、只想稳稳收下的时候——不要最狠的，要最不容易翻车的那一手。
5. 平衡二（二手平衡）
   对前 K 个候选**逐个虚拟落子**，再问对手最强的应手，取「走完这两手之后 |评估| 最小」
   的那一对：≡ 是我要走的那一手，↩ 是预计对手会应的那一手（这两手都标在盘上）。
   用途：开局 / 中盘想挑一个「交换之后仍是均势」的落点，比只看一手更稳。

·1）三颗分析键（多点分析 / 扫描防守 / 平衡一 / 平衡二）**互斥高亮**：点谁谁亮，
  换一个就换亮。「计算 / 停止计算」那颗键不参与互斥，只跟「是否在算」走。
·2） 想让结论更可靠：加大「对局设置 → 思考时间」（秒）、把「核心数」调到机器实际核数；
  代价是每次分析等得更久。分析点数只影响多点分析与平衡一/二，不影响「计算」。
· 3）配套的两块显示（也在本卡里）：
  · 4）AI视图 —— 勾选后，AI 思考时只在盘上标出**它准备下的那一点**，落子即消失；
  · 5）指导视图 —— 方形四色热力，把候选按「最佳 / 良好 / 一般 / 劣势」四档铺开，落子即消失。

【前瞻：把残局一路推到五子连珠】
1. 它是什么
   从（当前局面）出发，引擎在一张临时盘上逐手取最佳点，一直推到出现五子连珠为止
   （或推满 60 手）。全程**不碰真棋盘**：推出来的子画成半透明 + 浅色渐变描边，
   紫 = 黑子、浅蓝 = 白子；框下会同步生成一条着法代码链（如 h8 i9 g7 …）。
2. 为什么它对残局特别有意义
   （1）残局的分支比中盘少得多、杀法也更明确，引擎推演的可信度最高——中盘要猜的
        「对手会怎么应」，在残局里往往只有一两条路，结论接近定论。
   （2）它把「离成五还有几手」变成**看得见的一整条链**。中盘里散落的冲四、活三，
        在残局里会连成连续冲四 / 四三杀的次序；前瞻直接把这条次序铺出来，
        一眼就能看出胜负手在第几手、先冲哪个四、什么时候该防守而不是进攻。
   （3）它能回答「这盘还有没有救」：如果链上是对手先连五，那就是已经被杀，
        再怎么挣扎也只是在拖——这时回头去看链上第几手才是真正走错的那一步，价值最大。
   （4）训练价值：先在脑子里（或纸上）想一遍自己的杀法，再开前瞻对照，
        看自己差在哪一手、是哪个次序排错了，比单纯看一个「最佳点」学得快得多。
   （5）它是**只读**的：推演只是预览，不落盘、不改局面、不影响历史，想看就看、想关就关。
3. 怎么用（完整步骤）
   （1）摆好残局：人机对弈或自由摆盘都可以（复盘窗口、已终局的对局不可用）。
   （2）点「前瞻」键 → 键变色 = 开启，框里显示「正在推演第 k 手」，
        棋盘上逐手冒出半透明推演子，框下的代码链同步变长。
   （3）浏览：鼠标**悬浮**框下某枚代码 = 预览「到这一手为止」的局势（鼠标移开不会闪）；
        右上角的 < > 键 = 在推演序列里逐手步进。
   （4）落地：点某枚代码 = **选中**（「确定」键随之点亮），点「确定」才把选中的那一手
        （含前面所有手）真正落上盘；可以分次累进确定——已确定之后的代号会变浅，
        但仍然可以再选、再确定，继续往下走。
   （5）确定之后结果**冻结**：局面再变也不会自动重算（不浪费时间、也不会把你看中的
        那条链冲掉）。想重推，再点一次「前瞻」键即可。
   （6）还没确定时，局面一变（你落子或 AI 落子）旧推演作废，前瞻开着就自动重推
        （300ms 去抖，防止连击）。
   （7）再点「前瞻」键 = 关闭（清掉推演子与代码链）；若当前是冻结状态，再点 = **重新计算**。
4. **VCF / VCT 算杀**（专治残局题）：
   框里第一行的 **VCF / VCT** 两颗键 = 只跑**本地算杀器**（VCF = 连续冲四必胜；
   VCT = 冲四 + 活三连续威胁必胜，迭代加深 + 多线程并行搜索）。点任意一颗开始，
   选中键变**浅粉紫**；一旦存在算杀必胜，直接把**完整必胜序列**铺出来——
   棋盘上推演子之外还会画一条**粉紫虚线**把杀路逐手串起来，一眼看出怎么走；
   框里会标明「VCF 算杀成功：n 手」或「VCT 算杀成功」；**没有就明确提示
   「没有找到 VCF/VCT 必胜杀」**，可换另一颗键或开「前瞻」逐手推演。
   残局题的连续冲四杀法不会再被逐手评估漏掉或推错。
   （布局：第一行 = 前瞻 + VCF / VCT + < > 步进；第二行 = 黑子 / 白子图例 + 确定键——
   图例用色框框住文字：黑子紫框、白子浅蓝框，与框下代码链同配色。）
   · **点击即有反馈**：点「前瞻」进入算杀后，框内 VCF / VCT 键会变成**粉紫色**
     （查找中与命中时点亮；关闭前瞻或未找到解时恢复原色），一眼能看出算杀是否在跑。
4. 两处要注意
   · 推演走的是**专用引擎车道**（不与热力图、AI 落子抢），每手预算 = 思考时间 × 2
     （下限 300ms、上限 1.2s）——想让残局推演更准，把「思考时间」调大最有效。
   · 推演结论**不代表绝对真理**：它只是引擎在这些时间预算下的判断，
     时间越长越可信；残局里若出现「推到一半换了条路」，通常是更深的一层找到了更快的杀。

【识图窗口（顶栏「识图」键）】
把图片或屏幕上的棋盘**读进训练器**接着下 / 保存 / 复盘。
1. 左侧图片面板：上传图片（可多选，最多 150 张）或屏幕截图；点「n / m」胶囊
   打开**图片抽屉**——点缩略图选中、右上角 ✕ 移除、点抽屉空白处也能触发上传。
   · **自动保存**：每次上传 / 截图的图片都会自动留在抽屉里，超过 150 张
     自动删掉最老的，不用手动管理；
   · 抽屉顶部有三个小键：**选择**（进入勾选模式）、**全选**、**删除**
     （删除勾选的图）；支持 Ctrl+点 多选、Shift+点 范围选、Ctrl+A 全选；
   · 勾选后可「复制图片」（把选中的图复制回识图区接着识别）；
   · 在缩略图上**右击**也会弹出这些操作。
2. 修改识别结果（「加载到练习」右边新增**「修改」键**）：机械识别偶尔会认错一两颗子，
   点「修改」后按键**分两行居中**排在棋盘正下方——第一行「交换黑白子 / 删除棋子 /
   补充黑子 / 补充白子」，第二行「添加黑白子 + 黑子开始 / 白子开始」单独占一行；
   修改模式下棋盘会显示**浅紫色预览框**
   （悬停提示），所有操作提示统一显示在**左侧文字栏**（字号稍大、更醒目）——
   · **交换黑白子**：**逐对交换**——先点一颗黑子，再点一颗白子，这两子瞬间互换颜色；
     可以连续换很多对，直到再点「交换黑白子」或按 Esc 退出（适合只错个别几颗的情况）；
   · **删除棋子**：点要删的子——黑比白多一时可**单独删黑子**，白与黑齐平时可**单独删白子**；
     其余情况会提示你再点一颗**对面颜色**的子成对删除（点错的子再点一下取消）；
   · **补充黑子 / 补充白子**（某一色缺子时用）：点键后提示补色，在空交叉点上
     **点一下补一颗**——补黑会补到「黑与白齐平或多一」为止，补白补到「白与黑齐平」为止，
     超了会提示；适合识别漏子 / 多子后把黑白数量修平；
   · **添加黑白子**：**「黑子开始 / 白子开始」**两键，一次补一对。以黑子开始为例：
     点一个空位出现**半透明黑子** → 再点一个空位出现半透明白子（两子用**虚线框**框住）
     → 点第三个位置 = 落定这一对并开始下一对；点棋盘外空白 = 只落定这一对。
     白子开始则顺序相反；
   · 在棋盘的某个格子上**右击**，也能直接呼出这些修改操作；
   · 改完随时再点「修改」收起功能条，识别结果以修改后的为准保存 / 加载；
   · **棋盘代码框**：识别 / 手工修改落定后，当前局面的**棋盘代码**会自动出现在
     功能键与提示文字之间的小代码框里（与主窗「局面代码」同格式），
     点「复制」即可拿去别处复用。
2. 屏幕截图（中空选框）：
   （1）点「屏幕截图」→ 屏幕上出现一个**天蓝色中空选框**，中间完全透明、
        不挡任何操作，可以照常操控其它软件；
   （2）拖天蓝标题栏 = 移动；拉四边 / 四角 = 缩放（边缘命中区较宽，光标好变）；
   （3）「自动 开」（默认开）= 自动贴棋盘：每隔 1~2 秒在屏幕上找一次五子棋棋盘，
        找到后选框自动贴到棋盘上，并**向外多留约棋盘 1/30 的余量**——
        最外一排棋子完整进图，识别不丢边缘子（与桌面端五子棋助手的自动贴盘同款手感）；
        不需要时点一下切「自动 关」；
   （4）摆好后点标题栏「截图」→ 框内区域立即进识图；**框保留**，挪个位置可接着截，
        只有「关闭」或 ESC 才收框；选框自身不会被拍进截图里；
   （5）窗口最小 880×580，右棋盘随窗口缩放、左侧图片框大小不变；
   （6）英文模式下选框的按键与标题同步为英文短词（Auto/Off · Shot · Close），
        键宽按字宽自适应；**关闭识图窗口时，截图框会跟着一起关闭**。
3. 识别：换图后自动识别，也可手动点「识别」；按提示语区分情况——
   「暂时没识别出棋盘和棋子」「识别到了棋盘但没读出棋子」「图片可能模糊」
   「图片分辨率较低」等。
   · **自动吸附（智能）**：识别大图时默认会「自动吸附棋盘区域」再精读一遍——
     只在整图直读**不可信**（黑白差异常等）时才启用，正常识别不会多绕路；
     吸附裁剪时会**向外多扩约棋盘 1/30 的余量**（与屏幕截图选框的自动贴盘同款口径），
     边缘细节保得住——全棋盘大图也能从吸附 + 外扩里受益，不需要任何开关；
4. 残棋盘容错：截图/照片拍不全 15 路整盘（比如只拍到半张盘、或非标准路数）时，
   按**等距晶格**重建网格：只要图里还剩 6 条以上的横竖格线、周期清晰，
   就能照常读子并居中加载，并提示「当前棋盘可能不完整（残盘），已按棋子排布居中加载」。
   · **边线被裁自动校正**：截图刚好裁掉最外一条格线（比如贴着第一路子截图）时，
     识别器会自动剔掉「幻影线」并把整盘**回正一个格**再读子——此前这类截图会
     整体错位一格、丢掉一排边缘子，现在能正确读出（仍会提示残盘、按棋子排布居中加载）。
5. 结果去向：「保存到历史」入历史抽屉；「加载到练习」把局面发到主窗口——
   若当前是人机模式会**自动切到自由摆盘**（静态盘面由你自己接着摆 / 研究）。

【复盘窗口】
1. 主窗口顶栏「复盘」打开独立复盘窗：只有棋盘 + 一行功能键（背诵 / 重放 /
   播放步进 / 速度），不连 AI、恒无禁手。
2. 主窗对局设置里的「预览框」开关会**同步到复盘窗**（悬停方框画不画两边一致），
   在主窗切换后复盘窗实时跟随。
3. 历史可改名 / 右键操作 / 导出导入 txt。

【注意】
1. 引擎与识别全部本地运行，不上传棋谱到任何服务器。
2. 识别效果受图片清晰度、棋盘占图比例影响：棋盘越大越清晰，读子越准。
3. 关闭窗口即退出；运行日志见 exe 旁 GomokuTrainer.log。
